= Incoming Message-Signaled Interrupt Controller (IMSIC) Device Library
Quintauris GmbH
:toc: left

Implements access to the IMSIC device.

== Type `rvbl_imsic_hart_t`

RISC-V HART identifier.

== Type `rvbl_imsic_interrupt_source_t`

RISC-V interrupt source identifier.

== Type `rvbl_imsic_interrupt_priority_t`

RISC-V interrupt priority value (same as identifier).

== Enumeration `rvbl_imsic_hart_mode_t`

Supported privilege modes for RISC-V HARTs.

`rvbl_imsic_mode_machine` :: Machine mode.

`rvbl_imsic_mode_supervisor` :: Supervisor mode.

== Constant `RVBL_DEVICE_IMSIC_INVALID_INTERRUPT_SOURCE`

Invalid interrupt source value.

== Enumeration `rvbl_imsic_hart_delivery_t`

Supported IMSIC delivery modes for RISC-V HARTs.

`rvbl_imsic_delivery_disabled` :: Interrupt delivery disabled.

`rvbl_imsic_delivery_enabled` :: Interrupt delivery enabled.

`rvbl_imsic_delivery_plic_or_aplic` :: Interrupt delivery through PLIC or APLIC.

== Function `rvbl_imsic_hart_set_delivery`

Sets HART interrupt delivery mode.

=== Parameters

`rvbl_imsic_hart_mode_t`:: Privilege mode of interrupt delivery mode.
`rvbl_imsic_hart_delivery_t`:: New HART interrupt delivery mode.

=== Return Value

`rvbl_result_success`:: Modification successful.
`rvbl_result_error_bounds`:: Mode or privilege out of bounds.

`rvbl_result_error_bounds`:: Mode or privilege out of bounds.
