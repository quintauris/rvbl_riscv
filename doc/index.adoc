== Overview

This layer extends the {project} "core" layer with models and libraries for basic elements of the RISC-V architecture:

* Unprivileged ISA
* Privileged ISA
* HART-local Interrupts
* Platform-local Interrupt Controller (PLIC)
* Advanced Platform-local Interrupt Controller (APLIC)
* Incoming Message-Signaled Interrupt Controller (IMSIC)
* Memory Protection, Caching and Coherence
* Semihosting
